# gpttrade

## Crypto-Macro Correlation Bot (Telegram)

Интерактивный Telegram-бот для макро- и корреляционного анализа BTC
относительно традиционных рынков (DXY, QQQ, SPY, NVDA, MSFT), с ML-моделью
прогноза роста BTC, экспертными правилами для торговли с плечом 3x-5x и
ежедневной автоматической рассылкой полного отчёта.

### Установка

```bash
pip install -r requirements.txt
```

Ключевые зависимости: `yfinance`, `pandas`, `numpy`, `scikit-learn`, `xgboost`,
`python-telegram-bot[job-queue]>=20.0`. Экстра `[job-queue]` подтягивает
APScheduler, на котором работает `JobQueue` (ежедневная рассылка).

### Запуск

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_бота"
export TELEGRAM_CHAT_ID="ваш_chat_id"   # чат для ежедневной рассылки в 09:00 UTC
python3 crypto_macro_bot.py
```

Бот работает в режиме long polling (`application.run_polling()`), процесс
не завершается сам — для фонового запуска используйте, например:

```bash
nohup python3 crypto_macro_bot.py > bot.log 2>&1 &
```

или системный сервис (systemd, supervisor, screen/tmux).

### Как пользоваться

1. Напишите боту `/start` (или `/menu`) — придёт приветствие и меню с кнопками:
   - 📊 **Макро-корреляции** — таблица корреляций BTC с DXY/QQQ/SPY/NVDA/MSFT на 30/90/180д.
   - 🤖 **ML-Прогноз** — запускает XGBoost (или RandomForest, если xgboost не установлен)
     и выдаёт вероятность роста BTC более чем на 2% за 3 дня.
   - 🧠 **Экспертные сигналы** — проверяет три правила для плеча 3x-5x (catch-up effect,
     давление DXY, сжатие волатильности перед импульсом).
   - 📝 **Полный отчёт** — сводный анализ: цены, корреляции, фаза рынка, ML-прогноз,
     сигналы и сценарий на 24-72ч.
2. Каждый день в **09:00 UTC** бот автоматически присылает «Полный отчёт» в чат,
   заданный переменной `TELEGRAM_CHAT_ID`.

Рыночные данные кэшируются на 15 минут (`CACHE_TTL_SECONDS`), чтобы не создавать
лишнюю нагрузку на Yahoo Finance при частых нажатиях кнопок разными пользователями.
Ошибки скачивания данных или обучения модели не приводят к падению бота — они
логируются и возвращаются пользователю как понятное сообщение.

Новые торговые правила добавляются функцией вида `rule_xxx(df) -> dict | None`,
зарегистрированной в списке `REGISTERED_RULES`.

## RSI-бот для Binance (`rsi_bot.py`)

Спотовый бот (только покупка → продажа, без плеча), торгует по индикатору RSI:

- **Покупка** — RSI закрытой свечи пересёк `RSI_BUY` (по умолчанию 30) снизу вверх, т.е.
  цена выходит из зоны перепроданности.
- **Продажа** — RSI пересёк `RSI_SELL` (70) сверху вниз, либо сработал стоп-лосс / тейк-профит.

Состояние (открытая позиция, P&L) сохраняется в `rsi_bot_state.json`, поэтому
после перезапуска бот продолжает с того же места.

### Режимы

| `MODE`    | Что происходит |
|-----------|----------------|
| `paper`   | По умолчанию. Реальные котировки, сделки только симулируются. Ключи не нужны. |
| `signals` | Бот только присылает сигналы, а сделку вы подтверждаете и исполняете через Binance MCP в Claude Code. Ключи не нужны. |
| `testnet` | Настоящие ордера на тестовой бирже Binance (ненастоящие деньги). Ключи с https://testnet.binance.vision |
| `live`    | Реальные деньги. Дополнительно требуется `CONFIRM_LIVE=yes`. |

### Настройки (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SYMBOL` | `BTC/USDT` | Торговая пара |
| `SYMBOLS` | — | Портфель: несколько пар через запятую (`BTC/USDT,ETH/USDT,…`). Каждая пара торгуется отдельно на `ORDER_USDT` |
| `STRATEGY` | `rsi` | `rsi`, `ema_cross`, `donchian`, `bollinger`, `macd` (см. «Стратегии») |
| `FAST_EMA` / `SLOW_EMA` | `20` / `100` | Периоды EMA для `ema_cross` |
| `CHANNEL_ENTRY` / `CHANNEL_EXIT` | `20` / `10` | Каналы Дончиана для `donchian` |
| `BB_PERIOD` / `BB_STD` | `20` / `2` | Полосы Боллинджера для `bollinger` |
| `TIMEFRAME` | `1h` | Таймфрейм свечей (`1m`, `5m`, `1h`, `4h`, `1d`…) |
| `RSI_PERIOD` | `14` | Период RSI |
| `RSI_BUY` / `RSI_SELL` | `30` / `70` | Уровни перепроданности / перекупленности |
| `ORDER_USDT` | `20` | Размер одной покупки в USDT |
| `STOP_LOSS_PCT` / `TAKE_PROFIT_PCT` | `3` / `6` | Стоп-лосс и тейк-профит в %, `0` — выключить |
| `TREND_EMA` | `200` | Фильтр тренда: покупать только когда цена выше EMA(N). `0` — выключить |
| `TRAILING_PCT` | `0` | Трейлинг-стоп: продать при откате на N% от максимума после покупки. `0` — выкл. |
| `MAX_LOSS_STREAK` / `PAUSE_HOURS` | `3` / `24` | После N убыточных сделок подряд — пауза в покупках на M часов. `0` — выкл. |
| `POLL_SECONDS` | `30` | Как часто опрашивать биржу |
| `SIGNAL_TTL_MINUTES` | `30` | Сколько минут сигнал ждёт подтверждения (режим `signals`) |
| `STATE_FILE` | `rsi_bot_state.json` | Файл состояния (позиция, P&L, сигналы) |
| `BINANCE_DATA_URL` | — | Зеркало рыночных данных для `paper`/`signals`/`backtest`, напр. `https://data-api.binance.vision/api/v3` (если `api.binance.com` недоступен в вашем регионе) |
| `BINANCE_API_KEY` / `BINANCE_API_SECRET` | — | Ключи API (для `testnet`/`live`) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | — | Необязательно: уведомления о сделках в Telegram |

### Запуск

```bash
pip install -r requirements.txt

# 1) Проверить стратегию на истории (ключи не нужны)
SYMBOL=BTC/USDT TIMEFRAME=1h python3 rsi_bot.py backtest

# 2) Бумажная торговля
python3 rsi_bot.py

# 3) Тестовая биржа
MODE=testnet BINANCE_API_KEY=... BINANCE_API_SECRET=... python3 rsi_bot.py

# 4) Реальная торговля — только после проверки на paper/testnet
MODE=live CONFIRM_LIVE=yes BINANCE_API_KEY=... BINANCE_API_SECRET=... python3 rsi_bot.py
```

### Стратегии и какая из них работает

| `STRATEGY` | Идея | Тип |
|---|---|---|
| `rsi` | купить, когда RSI выходит из перепроданности; продать при выходе из перекупленности | возврат к среднему |
| `bollinger` | купить, когда цена возвращается внутрь нижней полосы Боллинджера; продать у средней | возврат к среднему |
| `ema_cross` | купить, когда быстрая EMA пересекает медленную снизу вверх; продать при обратном пересечении | следование за трендом |
| `donchian` | купить при пробое максимума за N свечей; продать при пробое минимума за M свечей («черепахи») | следование за трендом |
| `macd` | пересечение MACD(12,26) и сигнальной линии (9) | тренд / импульс |

Поверх любой стратегии работают `STOP_LOSS_PCT`, `TAKE_PROFIT_PCT`, `TRAILING_PCT`,
фильтр тренда `TREND_EMA` и пауза после серии убытков `MAX_LOSS_STREAK`.

#### Честная проверка: walk-forward

```bash
python3 rsi_bot.py optimize --strategy all --candles 6000 --folds 3
```

История делится на 4 части. Параметры подбираются по прошлому, а проверяются на
следующей части, которую бот при подборе не видел, — и так три раза. Строка
**ИТОГО на новых данных** показывает, как бот торговал бы вживую. Если стратегия
красиво выглядит только на обучении — это подгонка под историю, торговать её нельзя.

#### Рекомендуемая настройка: портфель из нескольких монет

Одна монета может месяцами падать или стоять. Если разделить сумму поровну
между несколькими монетами, их тренды случаются в разное время, и общая
просадка заметно меньше. Каждая пара торгуется независимо, на `ORDER_USDT`:

```bash
STRATEGY=ema_cross FAST_EMA=10 SLOW_EMA=50 TIMEFRAME=1d \
  STOP_LOSS_PCT=0 TAKE_PROFIT_PCT=0 TRAILING_PCT=0 TREND_EMA=0 MAX_LOSS_STREAK=0 \
  SYMBOLS=BTC/USDT,ETH/USDT,SOL/USDT,BNB/USDT,XRP/USDT,ADA/USDT ORDER_USDT=25 \
  SIGNAL_TTL_MINUTES=720 MODE=signals python3 rsi_bot.py
```

`SIGNAL_TTL_MINUTES=720` — сигнал дневной стратегии появляется в 00:00 UTC и
ждёт подтверждения 12 часов. Бэктест того же портфеля:

```bash
SYMBOLS=BTC/USDT,ETH/USDT,SOL/USDT,BNB/USDT,XRP/USDT,ADA/USDT ORDER_USDT=25 \
  STRATEGY=ema_cross FAST_EMA=10 SLOW_EMA=50 TIMEFRAME=1d STOP_LOSS_PCT=0 \
  TAKE_PROFIT_PCT=0 TREND_EMA=0 MAX_LOSS_STREAK=0 python3 rsi_bot.py portfolio --candles 1150
```

Результаты портфеля из 6 монет (EMA 10/50, 1d, по 25 USDT на монету):

| Период | Портфель | его просадка | Купить и держать | его просадка |
|---|---|---|---|---|
| 2020-08 — 2026-10 | +2525% | 53% | +1278% | 85% |
| 2023-08 — 2026-10 (3 года) | +97% | **35%** | +170% | 65% |
| 2025-02 — 2026-10 (рынок вниз) | **+16%** | 33% | −22% | 65% |

Портфель не всегда зарабатывает больше рынка: за последние 3 года «купить и
держать» дал больше. Но просадка в портфеле **примерно вдвое меньше**, а в
падающем рынке он остаётся в плюсе. Честные оговорки: монеты выбраны из тех,
что сейчас в топе (выжившие), а параметры EMA 10/50 найдены на этой же
истории — реальные результаты, скорее всего, будут скромнее.

Чего ждать от трендовой стратегии:

- **Большинство сделок убыточные (55–80%)**, но они маленькие, а редкие
  прибыльные — большие (profit factor 2–17). Это нормально: стратегия зарабатывает
  на крупных трендах и много раз «пробует» вход.
- **Просадки всё равно большие — 50–85%**, хотя обычно меньше, чем у «купить и
  держать». Месяцами может не быть прибыли. Вкладывайте только то, что готовы
  долго не трогать.
- **Сделок мало — 3–5 в год.** Сигнал бывает раз в несколько недель, после
  закрытия дневной свечи (00:00 UTC).
- Прошлые результаты не гарантируют будущих. Сначала 1–2 месяца в `paper` /
  `signals`, потом небольшая сумма.

### Защита от убытков (для любой стратегии)

- **Фильтр тренда `TREND_EMA`** — покупать только выше EMA(N).
- **Стоп-лосс, тейк-профит, трейлинг-стоп** — ограничивают убыток и фиксируют прибыль.
- **Пауза после серии убытков** — если рынок «не тот», бот перестаёт покупать.

Метрики бэктеста: доходность, % прибыльных сделок, profit factor (сумма
прибылей / сумма убытков, больше 1 — хорошо), максимальная просадка.

### Режим сигналов с подтверждением через Binance MCP

В этом режиме у бота нет доступа к деньгам: он считает RSI по публичным свечам
Binance и при сигнале присылает уведомление (в консоль и в Telegram). Сделку
исполняет Claude Code через [официальный Binance MCP](https://developers.binance.com/en/docs/agent-native/mcp-server/agentic),
и только после вашего «да». Торговля идёт внутри Agentic-субаккаунта, а вывода
средств у MCP нет совсем.

1. Один раз подключите MCP на своём компьютере (Claude Code):
   ```bash
   claude mcp add binance-mcp-server --transport http https://agent.binance.com/mcp/agentic
   ```
   затем `/mcp` → `binance-mcp-server` → авторизация (права Market data, Account,
   Trade → Spot). Переведите в Agentic-субаккаунт только сумму, которой готовы рискнуть.
2. Запустите бота в режиме сигналов:
   ```bash
   MODE=signals SYMBOL=BTC/USDT TIMEFRAME=1h ORDER_USDT=20 python3 rsi_bot.py
   ```
3. Когда придёт «🔔 Сигнал …», откройте Claude Code в папке репозитория и
   введите `/rsi-signals`. Навык `.claude/skills/rsi-signals` покажет сигнал,
   текущую цену и баланс и спросит подтверждение. После «да» он поставит
   рыночный ордер через MCP (Binance тоже попросит подтвердить) и запишет
   исполнение в бота.

Команды для ручной работы с сигналами:

```bash
python3 rsi_bot.py signals                       # ожидающие сигналы и позиции всех пар (JSON)
python3 rsi_bot.py confirm <id> --price 64000 --amount 0.000312 --quote 20
python3 rsi_bot.py reject <id>
```

Если сигнал не подтвердить за `SIGNAL_TTL_MINUTES`, он истекает. Сигнал на
продажу (по RSI, стоп-лоссу или тейк-профиту) появляется только после
подтверждённой покупки.

### Безопасность API-ключа

При создании ключа на Binance включите **только «Enable Spot & Margin Trading»**,
**не** включайте вывод средств (Withdrawals) и ограничьте ключ по IP вашего сервера.
Не коммитьте ключи в репозиторий.

> ⚠️ RSI-стратегия не гарантирует прибыль: в сильном тренде вниз она может
> несколько раз подряд закрываться по стоп-лоссу. Сначала прогоните бэктест и
> бумажный режим, начинайте с небольших сумм.
