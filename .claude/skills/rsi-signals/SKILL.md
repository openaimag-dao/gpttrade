# Сигналы RSI → Binance MCP

Бот `rsi_bot.py` в режиме `MODE=signals` сам не торгует: он пишет сигналы в
файл состояния. Твоя задача — показать сигнал пользователю, после его явного
«да» исполнить его через Binance MCP и записать результат обратно в бота.

## Правила безопасности (обязательны)

- Никогда не ставь ордер без явного подтверждения пользователя в этом диалоге
  для **конкретного** сигнала. Ответ «да» на один сигнал не переносится на другие.
- Торгуй только спот, только рыночный ордер, только пара и сумма из сигнала.
  Не увеличивай сумму, не используй маржу, фьючерсы, плечо и переводы.
- Если сигнал устарел, цена ушла больше чем на 1% от цены сигнала, или чего-то
  не хватает (нет MCP, нет баланса) — не торгуй, объясни причину.
- Binance MCP сам попросит подтверждение ордера — это второй уровень защиты,
  не пропускай его.

## Шаги

1. Выполни `python3 rsi_bot.py signals` (с теми же переменными окружения
   `SYMBOL`/`STATE_FILE`, что у работающего бота). Если `pending` пуст —
   скажи, что сигналов нет, и покажи текущую позицию.
2. Проверь, что сервер `binance-mcp-server` подключён (инструменты Binance MCP
   доступны). Если нет — дай пользователю команду
   `claude mcp add binance-mcp-server --transport http https://agent.binance.com/mcp/agentic`
   и попроси авторизоваться через `/mcp`. Сам адрес не открывай и сервер не добавляй.
3. Через Binance MCP получи текущую цену `mcp_symbol` и баланс Agentic-субаккаунта
   (USDT для покупки, базовая монета для продажи).
4. Покажи пользователю: id сигнала, действие (купить на `quote_usdt` USDT /
   продать `amount`), цену сигнала и текущую цену с отклонением в %, причину
   (`reason`), сколько минут сигнал ещё действует, баланс. Спроси: исполнить?
5. «Нет» → `python3 rsi_bot.py reject <id>`.
6. «Да» → через Binance MCP:
   - buy: рыночная покупка `mcp_symbol` на сумму `quote_usdt` в USDT (quote order qty);
   - sell: рыночная продажа `amount` базовой монеты (не больше свободного баланса,
     округли вниз до шага лота).
7. Проверь через MCP, что ордер исполнен (`FILLED`), возьми среднюю цену,
   исполненное количество и комиссию. Затем запиши в бота:
   `python3 rsi_bot.py confirm <id> --price <средняя цена> --amount <кол-во монеты за вычетом комиссии в монете> --quote <USDT потрачено/получено с учётом комиссии>`
8. Сообщи итог: что исполнено, по какой цене, P&L сделки (для продажи) — из
   вывода `python3 rsi_bot.py signals`.

Если ордер исполнился частично или с ошибкой — не повторяй его автоматически:
покажи пользователю статус и спроси, что делать.
